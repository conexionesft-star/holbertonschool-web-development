# HTML, advanced — README

Proyecto para construir la estructura **HTML semántica** (sin CSS/JS) a partir del diseño en Figma.

## Objetivo
- Practicar estructura y semántica HTML.
- Replicar el armazón del diseño (header, secciones, footer) sin estilos.
- Validar con el W3C.

## Recursos
- Figma duplicado en mis Drafts.
- Validator: https://validator.w3.org/
- MDN HTML.

## Requisitos
- Solo HTML (sin librerías externas).
- Archivos con nueva línea final.
- Código válido W3C y semántico (alt en imágenes, orden de headings).
