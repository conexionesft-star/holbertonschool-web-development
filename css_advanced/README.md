# CSS, advanced

## Description
This project focuses on learning advanced **CSS** concepts to style and structure a professional webpage.  
It builds on the previous project **HTML, advanced**, reusing its structure and applying complete CSS styling according to a Figma design.

---

## Learning Objectives
At the end of this project, you should be able to explain:

- What CSS is and how it works
- How to add style to an HTML element
- What classes and selectors are
- How to compute CSS specificity
- What are the Box Model properties in CSS
- How browsers load and render web pages
